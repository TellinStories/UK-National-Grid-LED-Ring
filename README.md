# UK-National-Grid-LED-Ring
12 LED ring showing the live GB electricity generation mix, plus clock and pomodoro modes. MicroPython, XIAO ESP32-C3.

Code for a project which shows a the UK National Grid on a 12 LED neopixel ring, as well as a clock and pomodoro timer.

Similar to an older clock-only project: https://github.com/TellinStories/RGB-LED-Ring-Clock-Pico

Build instructions, 3d printed files etc. to follow
